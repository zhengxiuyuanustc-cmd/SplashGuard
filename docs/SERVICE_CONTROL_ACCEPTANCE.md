## 新增场景

| 操作 | 负向观察 | 同一测试的恢复检查 |
| --- | --- | --- |
| 在目标应用前台暂停 | 合成广告保持、无节点动作 | 本人重新启用后实际点击退出广告 |
| 取消目标应用选择 | 旧选择快照不得继续点击 | 重新选择后实际退出广告 |
| 进入并退出仅查看指引 | 两阶段均保持暂停、不点击 | 单独启用后才实际退出广告 |
| 系统撤销服务 | 实际连接先断开，随后广告不被点击 | 系统重新连接后实际退出广告 |
| 关闭并移除工具首页任务 | 任务确实消失，绑定服务仍连接 | 独立测试应用的广告仍被实际关闭 |
| 出现小窗口相似按钮 | 标签与屏幕位置满足原几何规则，但服务不得点击小窗口 | 关闭弹窗后，同应用全屏合成广告仍可被处理 |

负向场景不仅检查操作计数，还检查按钮持续存在、内容页未出现；每个可恢复场景再验证实际节点动作，避免把服务本来就没运行误记为拒点成功。小窗口用例先核验其按钮确实满足既有标签和屏幕几何条件，避免因位置不合格造成假阳性。

## 范围

只在显式确认的空白模拟器运行，仍要求isolatedEmulator=true和ro.kernel.qemu=1。系统服务授权变更、偏好清空及仅合成数据截图不操作个人手机。UiAutomation仍设置FLAG_DONT_SUPPRESS_ACCESSIBILITY_SERVICES，防止测试工具压制被测服务。

关闭首页使用Android finishAndRemoveTask，并核验该任务不再出现在本应用任务列表；不能据此承诺厂商清理器、强行停止、进程被杀、长时间后台或重启行为相同。服务撤权由隔离模拟器shell配置，不覆盖厂商授权界面。测试配置直接使用应用现有偏好入口，不代表所有首页按钮布局均已验收。

原有真广告证据保持独立：华为HarmonyOS4.2/B站9.16.1一次保留进程切回天猫广告提前关闭。合成测试不新增手机或真实素材兼容声明；原生鸿蒙自动跳过仍不支持。

代码位于app/src/androidTest，仅进入测试APK。正式发行包仍须通过Manifest隔离检查，不含测试组件、测试Provider或联网权限。无需因此重新安装用户手机或发布新版本。
