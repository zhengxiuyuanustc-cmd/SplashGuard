核验日期：2026-10-26。这里只记录已查到的厂商资料及可采用的指引，**没有在对应手机上完成实机验收**。官方域名上的普通用户帖子不当作厂商承诺；设置项可能因地区、机型和系统版本不同而缺失。

## vivo／iQOO：优先找开屏专用的动作权限选项

vivo官方账号“OriginOS原系统”发布的[Vol.157系统升级资讯](https://bbs.vivo.com.cn/newbbs/thread/38069132)（页面标注“vivo官方”，编辑于2024-12-27）在 **X100 Ultra / 15.1.12.1.W10.V000L1** 的升级记录中确认了开屏场景的传感器限制选项。该段还区分首次升级OriginOS 5与此前已经升级的设备，不能把公告的全部机型列表视为每项功能的支持列表。

可让本人按实际页面检查：

1. 设置 → 隐私 → 权限管理 → 权限 → 访问设备动作与方向。
2. 只检查存在摇一摇广告的目标应用。
3. **只有实际提供“仅开屏时禁止”等明确开屏专用选项时，才选择该项。** 不用长期禁止动作/方向访问来替代。
4. 返回目标应用验证广告与正常旋转、体感功能；打开指南并不代表已设置成功。

这条路径和选项来自上述特定版本公告，不保证所有OriginOS 5/6/7、全部vivo/iQOO或海外Funtouch OS均存在。本工具不读取也不自动修改该系统选项。对其他机型，先搜索实际设置并阅读系统说明；找不到开屏专用项时保留正常方向权限，改查应用内广告专用开关。

[vivo Y500产品页](https://www.vivo.com.cn/vivo/y500/)和[Y300 Pro+产品页](https://www.vivo.com.cn/vivo/y300proplus/)也确认有用于限制摇一摇广告的动作与方向管控能力；产品营销页没有给出“仅开屏”选项的完整版本清单，因此它们不能独立证明所有机型都支持这一具体选项。

- [vivo官方客服：应用软件接收消息不提醒](https://kefu.vivo.com.cn/robot/imgmsgData/3dfcdb616d0542b4baa4e9ead6d75c5e/index_1.html)（2023-01-03）给出了针对单个应用的后台检查入口：设置 → 应用与权限 → 权限管理 → 权限 → 自启动；设置 → 电池 → 后台耗电管理；以及多任务卡片下滑加锁。此处仅借用后台入口，不能把消息通知的整套排障照搬为本工具必需权限。
- 如服务确实被后台停止，可只针对“开屏清净”按实际选项允许所需的后台运行，再回App确认**服务实际连接**并实测。自启动、加锁和允许后台耗电不等于无障碍授权，也不保证强行停止、重启或资源压力下永久存活。

已检索到的“vivo V29 / Funtouch OS 15受限设置”帖子来自官方社区的普通账号，作者不是可核实的厂商技术支持，本次不把它当通用于国内OriginOS的官方解锁路径。遇到受限设置应保留提示原文，按本机适用的系统指引处理，不关闭全机安全保护。

## 魅族：存在开屏专用限制的明确历史证据

[Flyme官方16th系统更新页](https://flyme.com/firmwarelist-174.html)完整可读取，标注 **16th、Flyme 8.1.9.0A、2023-12-29**。更新记录的“手机管家”部分说明新增了加速度传感器管理，并允许仅在应用开屏时拒绝调用，以减少摇一摇跳转。

可纳入App的保守指引：部分Flyme版本提供开屏专用的加速度传感器限制。可在本机手机管家/权限设置中搜索相关项目；**只有系统实际提供“仅在开屏时拒绝”时才针对目标应用使用**。官方该页没有给完整菜单路径，本次不编造多级路径，也不将历史16th公告推广为所有Flyme或新机型已支持。缺少专用项时不要改成长期禁用加速度计。
