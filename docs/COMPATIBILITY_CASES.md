## 其他手机的最小反馈

优先使用[免登录兼容试用与本地反馈页](https://zhengxiuyuanustc-cmd.github.io/xiuyuanzheng.github.io/splashguard/testing/)：可直接下载0.1.16候选，在本页整理文字后自愿交给邀请人，不会自动上传或保存到服务器。也可使用[GitHub问题模板](../.github/ISSUE_TEMPLATE/bug_report.yml)。必要信息为本工具及目标App版本、型号与完整系统、实际现象和界面显示的服务状态；运行环境不知道就留空，不设额外门槛。

按原因推进：系统明确不支持 → 官方能力确认／指南；授权已开但服务未连接 → 该品牌后台与连接排查；服务已连、有广告且未跳过 → 具体按钮样式与有限样本；误触 → 先暂停相关规则并审查真假候选；未出现广告 → 暂不能验证。不能只用操作计数证明广告关闭。

不要求购买测试机、全开权限、关闭全机安全或整体方向功能。后续真机矩阵优先采用志愿者本人确认、脱敏的有限证据，不自动上传账号画面或私人日志。

0.1.16生产代码未变，后续Android8/15/17隔离模拟器每个系统16项检查已通过；本次新增服务控制与小窗口用例的边界见[SERVICE_CONTROL_ACCEPTANCE](SERVICE_CONTROL_ACCEPTANCE.md)。模拟器不把上表未知荣耀型号标成已适配，也不改变原生鸿蒙的能力结论。
