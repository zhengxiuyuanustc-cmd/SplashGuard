# 用户主动的脱敏规则夹具与真实离线回放

本页对应0.1.11候选。与DiagnosticSample.replay的结论解释不同，RuleReplay.evaluate会重新调用AdRules、RuleCatalog／RuleEvaluator和CandidateSelection，检查在当前内置匹配规则下是否无匹配、唯一匹配、身份冲突或输入扫描不完整。它不授予Android动作权限，不验证真实广告已关闭，不重建原页面。

## 从手机取得夹具

在离线工具中打开“规则夹具与离线回放”，先本人准备。服务、功能或应用选择未就绪时不会自动补齐授权；默认不记录夹具。最多等待2分钟，在下一所选应用本次短暂开屏内暂存有限线索。采集使用独立诊断时限，不修改自动点击的12秒/两轮预算，也不在普通页面延长扫描。多次观察同包不续期；切入其他所选应用后不转录第二个目标。

仅内存保留最近有候选的匹配输入；不会自动落盘、截图、上传或连续记录账号页面。查看时固定一份预览，再决定是否导出。旋转可保留进程内任务和预览，进程死亡不自动恢复内容或重放操作；取消准备或清除本地操作记录会清除当前夹具。已经导出的文件需本人自行删除。

## 只允许的字段

- 包类别固定BILI、ZHIHU、OTHER_SELECTED，其他精确包名不导出；版本数字可为未知-1，版本名称仅固定BILI9150／OTHER／UNKNOWN。
- 目标和祖先的固定ID、类名类别；文字和描述分别只保留严格已知的跳过语法，其他文字折叠OTHER，危险语义折叠UNSAFE。不会保留原始账号文字、完整资源标识或任意类名。
- 当前屏幕尺寸、候选边界、可见/启用/可点击及祖先完整标记。尺寸与边界用于重算原有几何条件，没有设备唯一标识；这比旧13字段诊断多，导出前应检查预览。
- 临时同帧身份用于表示同一节点的等价句柄，只有0至63，不是真实系统nodeId或设备ID。不同身份不按相同文字/位置合并；同身份而属性不一致的输入拒绝。
- 原扫描观察到的广告证据、B站开屏标记和扫描完整性事实，不包含整幅广告或整个控件树。

最多64个潜在候选、32层祖先，64KiB文件；超限、不完整或无法安全表达时不能假装已取得完整唯一目标。只覆盖现有识别提示，未知布局或没有可访问控件可能只有空夹具，不能靠它还原未采集页面。

## 文件边界与结果解释

文件必须精确符合受限Schema，枚举、类型、整数、深度、UTF-8和重复字段均校验；不接受正则、脚本、新规则、URL、原始页面字符串或预先填写的“匹配成功”结论。导入只供重新计算，不影响规则、应用选择、系统权限、兼容开关或手机动作。

夹具中的身份和证据仍是输入声明，不认证按钮真假或文件来源；人工改写文件不能获得控制手机的权限。回放不覆盖当前服务连接、完整前台窗口、当前应用选择、离线规则限制、会话预算或提交前的再次扫描；这些在Android运行路径独立执行。versionVerified只指内置规则声明的版本条件命中，不是手势许可。

无正反例或真机验收时，不据唯一匹配报告成功率。现有结论样本和新规则夹具分别存储、分别说明，不把旧解释按钮改名为“真实回放”冒充实现。
