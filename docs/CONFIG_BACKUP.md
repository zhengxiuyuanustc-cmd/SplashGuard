# 本地应用选择备份

应用选择备份只保存“希望开屏清净处理哪些应用”的明确包名列表，不是系统备份，也不是整个偏好文件的转储。具体版本的界面与整合验证以[测试记录](../TESTING.md)为准。

## 保存范围

文件只有两个字段：版本号`schemaVersion`和应用包名列表`selectedApps`。不包含操作记录、诊断样本、截图、账号、设备标识、完整已安装应用清单、系统授权、广告传感器开关、规则状态或手势兼容设置。功能开关和首次向导也不在文件里。

```json
{"schemaVersion":1,"selectedApps":["com.example.music","org.example.reader"]}
```

示例只是格式，不是建议处理的真实应用。包名按稳定顺序导出；空列表有效。文件最多64 KiB，最多128个包名，每个最多160个ASCII字符，必须是分段包名，不接受通配符、URL或脚本。重复包名、未知或缺失字段、非法文字、类型转换、无效版本和超限输入均拒绝。

该文件包含你选择处理的应用包名，可能反映应用使用偏好。导出前应查看内容，由本人选择本地保存位置及是否分享；若选择云盘文件提供者，联网和同步由该提供者负责。开屏清净不会自动上传文件，也没有为备份新增联网权限。文件没有作者签名认证，解析成功不证明来源或真实性。

## 恢复边界

解码文件只得到应用列表，不会触碰Android设置或执行动作。恢复界面应先显示将要恢复的应用、当前环境可找到的目标与将被替换的选择，只有本人确认后才应用；未知或未安装的目标不能冒充已安装成功。

确认恢复时，自动跳过应保持暂停，由本人核对目标和服务状态后再开启。不得从文件开启无障碍、手势兼容、后台例外或原生广告传感器选项；既有规则限制、系统授权和其他设置不应被备份文件覆盖。取消、解析失败或预览失败不改变当前选择。

清除App内记录不能替你删除已经导出的文件，卸载后也可能仍留在公共文件夹或云盘，需要本人按保存位置管理。

## 代码接口与验证

`ConfigBackup`不依赖Android。`new ConfigBackup(Collection<String>)`复制并校验输入，公开的`selectedApps`是不可变的排序列表；`encode`／`decode`和`toJson`使用共用受限JSON解析边界。恢复时的当前环境过滤、本人确认及强制暂停由Android接线负责，不能只因模型通过就称整套恢复已实机验证。

独立77项回归覆盖包名与数量边界、规范化排序、重复转义、精确字段、禁止权限／规则／执行字段、输入大小及类型；与共用Codec的172项检查同时通过。UI与完整构建结果由整合测试记录另列。
