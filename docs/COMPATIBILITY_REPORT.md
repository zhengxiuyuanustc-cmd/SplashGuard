# 本人预览的兼容报告（0.1.12候选）

目的是帮助其他手机区分授权查询、实际服务连接、应用选择和规则漏过。它不判断所有机型是否支持、不证明广告关闭，也不解除原生鸿蒙限制。已有本机广告问题由用户确认解决，后续优先其他设备的自愿反馈。

## 使用与数据

入口在设置／本机帮助中的“兼容报告”。进入页面仅生成内存快照，本人重新检查才更新。运行方式默认未知；默认安装仍记未知，手选兼容工具或分身只代表本人报告，不能根据Android API猜鸿蒙版本或跨环境能力。

固定字段：Schema、本工具版本、品牌／型号、Android运行环境、本人选择的运行方式、仅指引与启用开关、系统启用列表查询、实际连接、本地规则可读取状态、所选应用数量；另只查询B站、百度、百度极速版、网易云四个已知应用的版本、查询结果与选择状态。未查到不等于全机未安装，读取受限保留未知。报告不导出完整应用选择、账号界面、任意节点树、截图、设备唯一标识、操作记录或文件路径。

预览包含所有导出事实，可展开JSON字段。文字先限长并移除控制／双向格式／Unicode行段分隔符，未知保留未知；固定应用白名单拒绝任意包和重复项。此清理是显示边界，不是对用户任意文本的隐私自动识别器。完整厂商系统版本尚不自动确认，可由分享者自行补充。

## 状态判定

- 仅指引、暂停、规则无法验证分别显示，不当作广告匹配失败。
- 启用列表不等于服务连接。已连接时，即使列表返回OFF，也不反复要求授权；报告保留差异，待观察实际广告。
- 已列启用但未连接，先排查连接与该机型后台；不据此声称规则不支持。
- 服务已连接但未选应用，先选择；其余仅表示可观察，未出现广告不能验证效果，计数不证明广告关闭。

首页与帮助改用同一系统查询：优先Android AccessibilityManager的启用服务列表，查询不可用时再使用本应用Secure条目回退；查询失败保留未知。实际连接来自本工具服务生命周期，单独显示。见[Android官方接口](https://developer.android.com/reference/android/view/accessibility/AccessibilityManager#getEnabledAccessibilityServiceList(int))。

## 文件、生命周期和权限

本人点击保存才用系统文件选择器创建JSON，未新增存储或联网权限，依据[Android SAF](https://developer.android.com/training/data-storage/shared/documents-files)。选择云盘后由对应提供者同步；本工具不自动上传、发送、导入或执行报告。也可本人复制到系统剪贴板，分享前自行核对。

导出锁定已预览的不可变字符串；文件窗口／写入期间不能重新检查或重复启动。旋转只保留进程内快照与任务；报告、待导出内容不进入系统恢复Bundle，进程死亡后不会恢复文件写入。取消不改设置，写入失败不自动重试，可能已创建的文件需本人检查。已导出或复制内容不因清除本工具记录／卸载而自动删除。

本轮纯逻辑覆盖状态优先级、未知值、固定字段、Unicode、大小、不可变预览和白名单。新报告的文件提供者、旋转大字体与多机型效果仍待自愿实机验收，不能把逻辑检查或构建通过写成已覆盖所有手机。
