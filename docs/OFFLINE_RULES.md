# 离线规则与最小诊断文件

本文描述已完成本地构建的0.1.9候选，尚未公开发布或进行本候选实机验收。网站0.1.7下载包没有本页的新工具入口。验证范围以[TESTING.md](../TESTING.md)为准；不因文件能解析就认为真实广告效果已通过。

## 先从默认设置使用

普通用户无需编辑或下载规则文件。保持默认控件点击，选择一两个需要处理的应用、本人开启无障碍并核对服务已连接即可。防摇一摇仍优先使用应用内的广告专用开关，不关闭手机全局方向感应。

高级工具用于收紧规则和检查失败原因，不是更激进的“全能模式”。默认不启用手势兼容；B站9.15.0已知场景的兼容开关也不能替代版本、真实祖先容器、应用选择和原有窗口限制。没有现场样本时，不建议为提高计数而开启。

## 导入只收紧已内置规则

本地规则目录有两个槽：`generic.splash`用于用户已选择应用的通用开屏判断，`bili.splash.skip`用于`tv.danmaku.bili`的专用判断。`@selected`只是前者沿用用户选择的范围标记，不是所有已安装应用的通配符；导入文件不能替用户选择应用。

JSON仅接受包名、版本码范围、处理时段、轮数、启用和手势能力上限等限制。它不能添加选择器、正则、脚本、URL、代码、新规则ID或新包名，也不能把关闭的规则/手势权限重新打开。匹配逻辑仍由随APK编译的代码提供。即使限制内保留`allowGesture: true`，也不代表实际可提交手势；精确版本、真实上下文和用户兼容开关仍需全部满足。

一次导入只能保持或收紧**当前有效状态与内置上限**：版本范围只能缩小，时段不能延长，轮数不能增加，已关闭项不能重新开启。省略某个已有规则时保留它当前的限制，不恢复默认。同ID规则包的版本需递增；包版本是文件自己的修订号，不是目标App版本。包名和规则ID不能更换。

例如，下面仅把通用规则缩短为8秒、最多一轮。此例不是推荐给所有用户的默认值；先导出当前限制再修改，避免用示例覆盖自己已收紧的范围：

```json
{
  "schemaVersion": 1,
  "id": "local.restriction",
  "version": 1,
  "rules": [
    {
      "id": "generic.splash",
      "packageName": "@selected",
      "minVersionCode": 0,
      "maxVersionCode": 9223372036854775807,
      "windowMs": 8000,
      "maxActions": 1,
      "enabled": true,
      "allowGesture": false
    }
  ]
}
```

`versionCode`是Android数字版本码，不是`9.15.0`这样的版本名称。超出允许范围、未知字段、重复字段、重复规则、非整数数值或损坏文本都会拒绝。文件最多64 KiB；最多128条限制，实际也只能引用现有目录条目。当前目录只有两项，不代表允许新增128个规则。

规则文件**没有作者签名真实性认证**。限制收紧和严格解析用于控制它能改变的范围，不能证明文件来自维护者。App不会联网获取或自动更新文件。文件可以使规则失效、缩短处理机会或降低跳过率，因此应用前需预览。

## 预览、应用和恢复

1. 在高级离线工具中导出当前限制模板，系统文件选择器由本人选择位置。选择本机存储可全程离线；若本人选择云盘等文件提供方，其联网和同步由该提供方处理。
2. 修改后从系统文件选择器导入。先核对预览内容，只有明确应用才保存；取消、解析失败、限制校验失败不改变当前规则。
3. 如刚导入的限制不适合，可撤销**最后一次**导入；只有一步，不在新旧状态间来回切换。
4. 如要重新开始，可明确选择恢复内置规则。它只恢复规则，不更改所选应用、自动跳过开关、首次向导或系统权限，也不会自动打开兼容开关。

当前限制、前一步快照及是否可撤销在手机私有偏好中一起保存。损坏状态不能静默当作默认宽松规则继续点击；应停止规则处理并由本人在工具页选择恢复内置。恢复/导入/兼容设置变化会使旧操作失效，不给同一应用自动重开12秒时段。

## 两种诊断信息要分清

| 项目 | 内容与用途 | 保存/分享方式 |
| --- | --- | --- |
| 设置帮助的自检摘要 | 品牌型号、Android运行环境、本工具版本、功能/系统启用/实际连接状态，以及B站、百度（含极速版）和网易云三类应用的版本与是否选中 | 本人点击才复制到系统剪贴板，不自动发送；分享前自行检查 |
| 高级工具的最小规则样本 | 固定原因/规则/应用类别/节点类型/祖先关系枚举，版本码、候选数，以及扫描完整、可点击、场景/目标命中、排除布尔值 | 最近一份仅在本进程内存中；本人预览后通过系统文件选择器导出 |

最小规则样本不含原始文字/描述、资源ID、精确包名或完整应用列表、设备型号/唯一标识、版本名称、坐标、截图、URL和账号画面。`OTHER_SELECTED`会合并其他所选应用，未知规则ID不会原样导出。因此它可能无法单独定位某个广告的新布局；请不要把“缺少具体页面”误认为自动采集失败。

原有少量本地操作记录仍会保存最近按钮文字/应用/时间和固定诊断原因，详见[隐私说明](../PRIVACY.md)。最小样本并不意味着这些旧记录被自动删除，也不会自动把旧记录混入样本文件。

## 离线复核的作用

导入样本只对其中固定事实重新给出保守判定解释，例如扫描不完整、多候选、版本未确认或需人工检查上下文。它不会读取当前屏幕、运行规则脚本或提交点击，不会重建原页面，也不能证明“这个按钮是真的”或“广告已正确关闭”。手工修改样本也不能获得操作手机的权限。

分享文件完全由本人决定。导出文件可能位于公共文件夹或云盘；清除App记录、恢复规则或卸载不能替你删除已导出的文件或系统剪贴板，应按需自行删除。App不自动上传任何诊断文件。
