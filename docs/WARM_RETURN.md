# 保留后台再切回的开屏广告（0.1.15）

用户报告：打开B站，保留后台切到其他软件，再返回时会重新展示开屏广告，工具有时未跳过。连接手机回读发现本工具为0.1.11/code12，B站9.16.1/code9161100。这个报告不等于已抓到失败现场的根节点，也不能把所有漏过归为同一个原因。

## 修正的具体缺口

旧逻辑在确实观察到不同前台包后，本来就会重新开始一轮；不要求目标进程被杀。但窗口事件合并后的扫描可能只读到空根节点，而此前会话已完成/过期时不会继续安排扫描，因此可能漏记离开或返回。

0.1.15在窗口状态变化时，使用独立的短时前台复查：最多1.6秒、12次，间隔120毫秒，读真实活动根节点。它在旧广告会话已结束时仍可运行，空根节点/未知窗口不重置会话。仅有事件包名、类名、界面刷新或同应用弹窗都不能重开动作预算。当前界面必须近全屏且属于选中应用、可启动应用、本工具或系统默认桌面；键盘/局部对话框/没有启动入口的系统面板不作为普通应用切换。MAIN/HOME查询只用于确认桌面，没有增加uses-permission或读取全部交互窗口。

确认离开再返回后，才开始新一轮最长12秒/两次动作；旧回调失效。原有规则、双候选拒点、提交前重验、坐标暂停及广告专用传感器设置仍保留。同一应用里很晚才出现的普通页面广告不因本修正获得无限处理时段；窗口不可读超过复查范围等情况仍可能漏过。
