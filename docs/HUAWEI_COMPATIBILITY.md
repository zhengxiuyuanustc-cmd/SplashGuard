# 华为、鸿蒙与荣耀兼容性：按实际问题分流

资料核验日期：2026-10-25。最初反馈原文为“华为不给应用开全权限”，随后用户补充实际设备为荣耀、报告Android 17，且无障碍和管理权限已开；型号、完整MagicOS/Android系统字符串及具体异常仍待核实。不能再把这个个案认定为华为鸿蒙权限故障，也不能把Android 17映射成某个HarmonyOS版本。下列是按品牌与环境区分的官方资料，不是新机型实测结果。

## 不使用“开全权限”的提示

开屏清净当前Android Manifest没有普通`uses-permission`声明，不请求联网、相机、联系人、悬浮窗等能力。服务上的`BIND_ACCESSIBILITY_SERVICE`是系统绑定服务的保护声明，不等于让用户在普通权限页“全部允许”。自动跳过需要本人在系统中开启相应无障碍服务，后台运行设置、目标应用自己的广告专用开关则是另外的项目。

因此，普通权限页没有一大串可开启项目可以是正常状态，不能将它诊断为失败。App应分别显示：功能开关、所选应用、无障碍是否已启用、服务是否实际连接，以及用户报告的系统/运行环境是否已验证；不把打开设置页面视为授权成功。

## 先确认系统与安装环境

1. 让用户核对关于本机显示的完整系统名称与版本，而不仅是“比4.2新”。华为官方资料明确列有HarmonyOS 4.3，不能把更新版本一律视为HarmonyOS 5/NEXT。
2. 华为手机可能运行HarmonyOS或EMUI；仅凭品牌为HUAWEI不能判定系统分支。
3. Android `SDK_INT`与`Build.VERSION.RELEASE`反映Android API/运行环境信息，不能据此声称已识别原生鸿蒙的完整系统版本。特别是兼容环境，不能把其中的Android版本当作外部宿主系统版本。
4. 最小反馈只需品牌/型号、用户确认的系统版本、安装来源类别、服务连接状态、具体错误文字；不索要IMEI、序列号、帐号、锁屏密码或完整系统日志。

后两项是本项目的工程与隐私建议，不是华为提供了自动检测所有兼容环境的API保证。

## HarmonyOS 4.x及以下：无障碍与后台分别检查

华为[无障碍中的第三方应用服务开关自动关闭](https://consumer.huawei.com/cn/support/content/zh-cn00410039/)明确限定本知识适用于HarmonyOS 4.x及以下，适用列表含4.2和4.3。文档将清理后台、重启后开关关闭与服务无法启动关联，并给出如下处理类别：

- 本人进入系统设置，搜索“无障碍”，在“已安装的服务/下载服务”中重新开启目标服务。
- 需要时在多任务界面给本应用卡片加锁。
- 在应用启动管理中将本应用改为手动管理，并按需允许自启动、关联启动、后台活动。

这些路径不能当作HarmonyOS 5及以上的通用路径，也不能把所有手机的后台行为视为一致。本项目实机覆盖仍仅有历史华为GOA-AL80 / HarmonyOS 4.2；官方列出4.3不等于开屏清净已在4.3验证。

华为[应用无法后台运行排查](https://consumer.huawei.com/cn/support/content/zh-cn00428704/)还说明长期后台受系统和应用省电机制影响。其联网、开发者选项等通用排查不适合全部照搬：本App不需要后台联网，也不要求用户为此关闭全机安全或把开发者模式当日常运行前提。调整仅针对本应用，之后仍要返回检查实际服务状态与实际广告效果。

## HarmonyOS 5及以上：旧启动管理入口可能已不存在

华为[手机/平板管家相关功能变更](https://consumer.huawei.com/cn/support/content/zh-cn16056653/)适用HarmonyOS 5.0及以上，说明不再独立预置旧管家App；应用启动管理等部分能力已由系统自动管理，不需要原来的手动操作。文档另列部分版本的桌面管家卡片入口，但不把它作为旧自启动三开关的替代授权入口。

因此，“找不到应用启动管理”“没有旧版的三个开关”不应直接提示为权限被拒绝，也不应反复让用户寻找不存在的旧入口。App应显示版本对应的说明，注明当前Android APK的该环境能力尚未完成验证，并保留官方说明入口和反馈具体提示的方式。

## APK能安装，不等于跨原生鸿蒙自动点击已支持

华为[HarmonyOS 5及以上应用下载安装介绍](https://consumer.huawei.com/cn/support/content/zh-cn16061787/)明确列出卓易通/出境易提供服务的应用，也说明分享或互联网下载的APK能否安装以卓易通实际支持为准。

所以不能简单写“HarmonyOS 5/6完全不能安装APK”。同样，能启动一个Android APK也不能据此承诺其Android无障碍服务可访问原生鸿蒙应用、其他兼容环境或整个宿主系统。本次没有取得官方对这些跨环境能力的保证，也没有做实机验证。应将“当前Android环境内的服务已连接”和“跨环境自动跳过已验证”分开，后者保持未验证。

如果用户反馈是HarmonyOS 5/NEXT/6及以上，或通过兼容工具安装，应优先确认安装环境与目标应用属于哪个环境，不能继续套用4.x授权步骤或声称只要再开某个权限就一定能使用。广告专用开关指引可继续按目标应用的实际版本核对，不依赖给本工具更多权限。

## 原生鸿蒙：已核实当前公开Kit限制，不能称已支持

2026-10-26进一步取得官网动态正文后，当前Accessibility Kit简介明确只列状态查询与事件发送，不支持通过节点查询获取界面节点/屏幕内容；旧节点/动作及相关连接回调有API12废弃标记。ExtensionAbility总览的三方实现表格不能覆盖具体Kit的当前能力限制。

因此当前APK及设置指南不代表纯血鸿蒙原生自动跳过，原生功能暂不支持；是否有适用于本用途的受控开放路径仍待华为正式确认。没有据此假定只要装DevEco或开发HAP即可解决。完整出处、元数据及已准备但未发送的咨询见[原生核验](HARMONY_NATIVE_FEASIBILITY.md)。用户目前没有纯血鸿蒙真机，不会把旧GOA-AL80/4.2当作原生5/6验证。

## 受限制设置与安全策略：只对实际提示给建议

华为[华为运动健康消息通知提示受限制设置](https://consumer.huawei.com/cn/support/content/zh-cn16052113/)描述的是Android 13手机从非应用市场安装该App后，通知使用权受限的情况。它不是已核实的所有华为鸿蒙无障碍授权通用说明。只有用户确实遇到对应受限提示、系统也实际提供针对本App的入口时，才应按适用版本提供说明；不凭这个页面生成所有华为手机都能点到的路径。

华为[自动下载安装软件排查](https://consumer.huawei.com/cn/support/content/zh-cn16018144/)将纯净模式与增强防护作为拦截恶意应用/诱导下载的保护能力；[应用市场安装排查](https://consumer.huawei.com/cn/support/content/zh-cn00445299/)又区分安装来源与安全策略。这些说明不能证明本次反馈就是增强防护导致，更不能把关闭全机防护作为本App默认设置步骤。

若系统明确判为风险或不给本应用授权入口，App应说明功能暂不可用，请用户核对官方来源、包名/签名并保留提示原文，必要时通过华为官方支持确认；不得用ADB、Root、模拟点击或关闭全局保护绕过本人授权。不能建议把整体方向、动作识别或传感器权限关闭来替代广告专用设置。

## 可直接实现的用户分流

| 用户看到的情况 | 应呈现的处理 |
| --- | --- |
| 普通权限页没有可全开的项目 | 解释本App未请求这些普通权限；引导检查无障碍服务，而非“开全权限” |
| 无障碍未开启 | 先解释读取/点击能力，由本人决定并进入系统实际提供的设置 |
| 已开启但服务没连接，或清后台/重启后失效 | 区分4.x后台流程与5+系统管理变更；返回后检查真实连接，不标成设置成功 |
| 系统提示受限制或风险，开关灰色 | 记录提示原文、系统/来源；只提供适用说明，不承诺自动修复或全局关闭安全 |
| HarmonyOS 5/NEXT/6或兼容工具安装 | 明确Android APK跨环境能力未验证；不要把能安装/能打开视为自动跳过已支持 |
| 型号/系统仍不确定 | 保留“未知”分支和手动选择，先显示通用权限解释，不套用4.2路径 |

可选故障分类信息在本机预览/导出即可，不应为这次排查新增联网、设备唯一标识读取或自动上传。华为官方[关于“跳过”文字被自动乱点的说明](https://consumer.huawei.com/cn/support/content/zh-cn16004167/)也表明仅凭文本容易误触；本项目现有场景与候选冲突限制应继续保留。

## 后续确认的荣耀个案：不沿用华为鸿蒙归因

荣耀有独立的MagicOS/Android设置与运行环境，应按荣耀实际品牌和版本分流。用户报告“Android 17”暂作为用户输入保留，不擅自改成Android API 17、MagicOS 17、HarmonyOS 5/6，或任何确定的版本映射。本次没有检索到可核验的荣耀官方Android 17专项无障碍兼容说明，不能据此宣布支持、已适配或不支持。

荣耀[应用无法后台运行排查](https://www.honor.com/cn/support/content/zh-cn00428704/)列有针对本App的后台活动、电池优化与卡片加锁检查；[后台重新启动说明](https://www.honor.com/cn/support/content/zh-cn00406916/)的适用列表含MagicOS 10与11，但不提供其Android 17映射，并说明资源紧张时加锁也可能被清理。只借鉴与本App相关的后台检查，不照搬通用文章中的清除数据、恢复出厂、关闭全局省电/省流量等步骤。

荣耀[无障碍总览](https://www.honor.com/cn/support/content/zh-cn15869276/)给出“设置 > 辅助功能 > 无障碍”入口；[设置/系统管家异常排查](https://www.honor.com/cn/support/content/zh-cn15890904/)提及“下载服务”列表，但那篇是另一故障的处理，不应将其中关闭未知服务/卸载应用的步骤直接用于本个案。入口是否与用户机型相同仍以实际系统为准。

用户已经表示权限开启时，应继续检查并分别记录：

1. 开屏清净内功能是否开启，系统是否列为已启用，以及服务是否实际连接；开启开关不等于持续连接。
2. B站、百度和网易云的具体安装版本、包名/应用分身所属环境与本工具所选应用是否一致。“百度”与“百度网盘”不能混为同一应用。
3. 本次启动是否确实出现广告、是否存在可访问跳过控件、是否仅匹配失败，或是否被多候选/不完整扫描保护拒点。
4. 未出现网易云广告应记为“未出现广告/缺少样本”，不能据此判自动跳过失败。

以上是本项目的诊断设计建议，尚不能代替该荣耀设备上的复现。无需再次要求用户“全开权限”或降低系统保护；先取得具体失败现象再判断是规则、服务连接、后台还是系统兼容问题。

## 本地帮助页面接入（未实机验证）

本地新增`SetupHelpActivity`与纯逻辑`DeviceGuidePolicy`，入口为`SetupHelpActivity.open(context, topic)`，topic支持`accessibility`、`background`、`no_skip`。页面按品牌分流；HarmonyOS家族只能由用户手选，荣耀不误用华为路径。它把系统可查询的启用状态、当前进程内服务连接和功能开关分别显示；系统启用查询失败时显示未知，不把打开设置视为成功。

常见应用检查只查询B站、百度（含极速版，非网盘）和网易云三类应用的版本及当前选择；仅在用户点击时把查到的已安装应用合并加入处理。复制自检摘要也是用户主动动作，只包含机型/Android运行环境、工具版本、服务/功能状态及上述应用信息，不包含完整应用列表或设备唯一标识，不自动上传。

页面不使用弹窗选择家族；返回系统设置仅刷新现有控件，保留手动家族和滚动状态。入口只使用标准Android无障碍设置与本应用详情设置，官方网页交给浏览器。该分流的33项纯逻辑检查已纳入0.1.9完整12程序598项通过，整包Android SDK 35构建与验签通过；尚无这台荣耀设备或新鸿蒙版本的实机验证，不能据此称已解决该反馈。
