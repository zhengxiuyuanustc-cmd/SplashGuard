此次仅让该精确原生广告布局自身提供场景条件，不再额外要求素材含有可访问的“广告／摇一摇”等文字。保留9.16.1与9161100双重版本、count_down/TextView、跳过语法、logo_layout/ViewGroup→root_container/ViewGroup的两个直接父节点、完整同包祖先、可点击原按钮及既有几何边界。两个容器仍不是全局广告标记；没有新增skip/root动作规则，没有取消通用广告证据条件。
