# 没有自动跳过时，先分清当前状态

本页对应本地0.1.10候选中的设置帮助，网站默认0.1.7的界面和入口可能不同。源码分支、构建候选与公开APK分别记录，不能把指引页面视为机型验收。官方路径只用于指引，不是该手机已通过实测的承诺。

## 不需要“开全权限”

开屏清净没有请求联网、相机、联系人、悬浮窗或设备管理员等普通权限。普通权限页面没有一排可开启选项可以是正常状态。自动跳过需要本人开启系统无障碍服务；不要求关闭全机安全保护或方向感应，不会自动操作授权窗口。

请分别检查四项，而不是只看“权限开了”：

1. App内“启用自动跳过”是否开启。
2. 目标应用是否在处理列表内。“百度”和“百度网盘”不是同一App；应用分身、工作资料或兼容环境也需核对。
3. 系统是否列为已启用。若系统查询受限，帮助页显示“暂时无法确认”，不将其当作未授权。
4. **服务实际连接**是否显示已连接。系统开关已开、打开过设置页面或普通管理权限已开，都不能证明服务正在工作。

无需为排查清除目标App数据或恢复出厂设置。先重新检查服务状态，再观察一次确实出现广告的启动；没出现广告只记为“未出现广告”。

## 先确认指引品牌，再看适用路径

帮助页先按本机制造商和品牌显示指引，也可在下拉框切换“自动识别”或手动查看其他品牌。共12个选项：华为、荣耀、小米／REDMI／POCO、OPPO、真我、一加、vivo、iQOO、三星、魅族、Google／Pixel和其他／不确定。手动切换只改变说明文字，不修改手机、不确认完整系统，也不改变当前设备的自检状态。

请在“关于本机”核对系统及地区。华为还需手选HarmonyOS家族；旧荣耀带Huawei制造商字段时仍优先荣耀。不要把Android API号当成完整MagicOS／HarmonyOS／ColorOS版本，也不把一加海外OxygenOS教程套给国行。

## 防摇一摇只用广告／开屏专用项

在防摇一摇页查看本机专用设置。部分OriginOS公告与Flyme历史固件记录提供“仅开屏时禁止／拒绝”的细分动作权限依据；只有本机实际出现这类专用选项时，才针对有广告的目标App使用。具体来源和版本见[多品牌兼容说明](MULTI_BRAND_COMPATIBILITY.md)。

没有专用项就保留正常方向、加速度和体感权限，优先查目标App自身广告开关。App不会自动读取、修改或确认这些系统设置；看过指南不代表完成，关闭个性化广告也不等于摇一摇关闭。

## 受限授权与系统保护

帮助页的系统限制说明可展开或收起，附Android官方链接。部分Android13及以后侧载场景有单App“允许受限设置”；仅在来源可信且本机实际提供对应入口时由本人处理。高级保护对经验证辅助工具的限制是另一机制，本App没有读取该模式状态，不以API号推断原因，也不要求关闭全机保护。

敏感界面还可能限制读取、控件动作或模拟触点。已授权不保证每个页面可操作，本项目不虚报残障辅助工具身份绕过。遇到这种情况可保留系统保护，继续使用App内广告专用设置或手动跳过；反复追加普通权限无助于识别新布局。

## 已连接仍漏过怎么办

保持真实情况：有无广告、哪个应用/版本、未跳过还是误跳转。多候选冲突、扫描不完整、未知布局或没有可访问控件时，软件会保守停止；不要通过全局坐标、关闭所有传感器或扩大授权来“修复”。

荣耀用户目前报告B站、百度广告出现但未跳过，网易云疑似未出现广告。具体型号、完整MagicOS、目标App版本、首页实际连接状态与失败控件样本尚不完整，因此本地候选不能标成已解决该机型。可先用帮助页检查常见应用，再由本人决定是否复制摘要；不必反复开启已经开启的普通管理选项。

如系统实际显示“受限”“风险”或灰色开关，请保留提示原文并核对可信下载来源，按本机为本应用提供的适用说明操作。软件不会要求全局关闭安全保护，亦不保证能自动绕过系统限制。
