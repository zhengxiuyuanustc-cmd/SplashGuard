# 没有自动跳过时，先分清当前状态

本页对应本地0.1.9候选中的设置帮助，尚未公开发布；网站0.1.7的界面和入口可能不同。官方路径只用于指引，不是该手机已通过实测的承诺。

## 不需要“开全权限”

开屏清净没有请求联网、相机、联系人、悬浮窗或设备管理员等普通权限。普通权限页面没有一排可开启选项可以是正常状态。自动跳过需要本人开启系统无障碍服务；不要求关闭全机安全保护或方向感应，不会自动操作授权窗口。

请分别检查四项，而不是只看“权限开了”：

1. App内“启用自动跳过”是否开启。
2. 目标应用是否在处理列表内。“百度”和“百度网盘”不是同一App；应用分身、工作资料或兼容环境也需核对。
3. 系统是否列为已启用。若系统查询受限，帮助页显示“暂时无法确认”，不将其当作未授权。
4. **服务实际连接**是否显示已连接。系统开关已开、打开过设置页面或普通管理权限已开，都不能证明服务正在工作。

无需为排查清除目标App数据或恢复出厂设置。先重新检查服务状态，再观察一次确实出现广告的启动；没出现广告只记为“未出现广告”。

## 按品牌和系统处理后台

| 环境 | 帮助方向 | 尚不能承诺的能力 |
| --- | --- | --- |
| 荣耀 MagicOS/Android | 按荣耀自身的无障碍/后台页面检查本应用，必要时按实际选项允许后台活动、应用启动和卡片加锁 | 加锁不保证资源不足或系统清理后长期存活；“Android 17”报告不足以确定具体系统或规则问题 |
| 华为 HarmonyOS 4.x | 用户核对完整版本后，参考官方无障碍及应用启动管理指引；旧后台三开关只针对本应用 | 官方资料列出4.3不等于开屏清净已在4.3实测；历史设备仅GOA-AL80/4.2 |
| 华为 HarmonyOS 5/NEXT/6及以上 | 旧启动管理部分能力由系统自动管理，找不到旧三开关不直接等于拒绝权限；确认APK与目标应用所属运行环境 | 能安装或打开APK不证明Android无障碍能操作原生鸿蒙或其他兼容环境 |
| 未知系统/其他品牌 | 保留未知，按实际页面检查无障碍、后台与服务连接 | 不凭Android API数字自动判断完整HarmonyOS版本，不照搬其他品牌路径 |

华为手机的系统家族由用户按“关于本机”实际显示手动选择。荣耀独立分流，即使某些旧荣耀设备制造商字段为Huawei，也不直接显示华为鸿蒙路径。详细官方来源与核验限制见[华为/荣耀兼容记录](HUAWEI_COMPATIBILITY.md)。

“关闭首页，保留自动跳过”只结束界面。系统强行停止、回收进程、关闭无障碍或重启可能使服务停止；软件不能自行重新授权。B站应用内的广告专用传感器开关由B站保存，不依赖本工具后台。

## 已连接仍漏过怎么办

保持真实情况：有无广告、哪个应用/版本、未跳过还是误跳转。多候选冲突、扫描不完整、未知布局或没有可访问控件时，软件会保守停止；不要通过全局坐标、关闭所有传感器或扩大授权来“修复”。

荣耀用户目前报告B站、百度广告出现但未跳过，网易云疑似未出现广告。具体型号、完整MagicOS、目标App版本、首页实际连接状态与失败控件样本尚不完整，因此本地候选不能标成已解决该机型。可先用帮助页检查常见应用，再由本人决定是否复制摘要；不必反复开启已经开启的普通管理选项。

如系统实际显示“受限”“风险”或灰色开关，请保留提示原文并核对可信下载来源，按本机为本应用提供的适用说明操作。软件不会要求全局关闭安全保护，亦不保证能自动绕过系统限制。

帮助页的“复制自检摘要”包含品牌型号、Android运行环境、本工具版本、功能与服务状态，以及B站、百度（含极速版）和网易云三类App的版本与选择。它不包含完整应用列表、设备唯一标识或账号画面，也不会自动发送。

高级工具另有不含型号、原始界面文字的[最小规则样本](OFFLINE_RULES.md)，用途不同。请先预览，再决定是否分享。无需发送PIN、密码、IMEI、序列号或完整系统日志。
