# 推进清单实际状态

更新：2026-10-26，0.1.11候选。本表按当时竞品比较后的顺序核对；代码实现、工程检查、实机效果与公开发行是不同状态，不以一项完成代替其他项。

| 原推进项 | 当前实现 | 仍欠的验收或范围 |
| --- | --- | --- |
| P0 节点／手势策略分离 | 已接入；默认节点动作，特例手势另受版本/上下文/用户开关限制，提交前重扫 | 收紧后的真实B站、双按钮和覆盖层实机矩阵未完成 |
| P0 有限上下文规则 | RuleSpec/Evaluator/Catalog支持版本、父链、祖先及排除；已接两个内置槽 | 新App/版本要有具体正反例，不能称未知布局都适配 |
| P1 最小样本及离线回放 | 旧13字段结论复核保留；0.1.11另增加本人准备的有限节点夹具，实际调用匹配器重新计算 | 不是完整页面重建，不覆盖Android动作/当前授权/预算/提交重验；新UI与采集实机尚未验收 |
| P1 离线规则／单条停用／撤销 | 现有槽只能收紧；界面可单独暂停通用/B站组并预览确认，支持一步撤销和恢复内置 | 没有作者验签或可新增选择器的动态规则包。新匹配规则仍随APK源码审阅/签名分发，限制JSON不冒充受信规则更新 |
| P1 机型指南与本地备份 | 12类官方文字指南、手动品牌、本人确认的仅指引模式；0.1.11备份所选应用列表，恢复需预览、重新过滤且强制暂停 | 尚无覆盖各机型的实拍图文教程；不是完整系统/权限备份；不捏造截图或恢复原生传感器开关 |
| 持续 标准构建／正式发布／实机矩阵 | SDK备用构建与797项纯Java通过；源码931f2b9的[标准Gradle assembleDebug+lintDebug](https://github.com/zhengxiuyuanustc-cmd/SplashGuard/actions/runs/40294858713)成功 | 正式非调试发行、多机型/长期后台/真实广告验收尚未完成 |
| 新增 原生鸿蒙 | 已核实当前官方Kit节点能力限制、旧接口废弃及第三方表格差异，已准备官方能力咨询 | 无原生HAP、当前没有纯血鸿蒙真机，原生自动跳过暂不支持；需官方支持的接口路径与设备证据 |

因此不能回答“整份推进清单已经全部完成”。本轮补齐了可独立实现的备份、直观规则暂停、真实匹配回放和标准构建检查入口；未完成项仍明确保留。没有把原生鸿蒙指南或APK兼容运行写成原生功能。

具体边界见[RULE_REPLAY](RULE_REPLAY.md)、[CONFIG_BACKUP](CONFIG_BACKUP.md)、[GRADLE_VALIDATION](GRADLE_VALIDATION.md)、[HARMONY_NATIVE_FEASIBILITY](HARMONY_NATIVE_FEASIBILITY.md)及[TESTING](../TESTING.md)。

后续优先扩展其他设备，已有本机广告问题由用户确认解决。机型个案、用户报告与实机证据的区别见[兼容反馈与验收范围](COMPATIBILITY_CASES.md)；鸿蒙7反馈者已确认版本0.1.7，默认安装方式仍不足以判断运行环境。
