## 两项功能，各自怎么起作用

| 功能 | 如何帮助你 | 边界 |
| --- | --- | --- |
| 防摇一摇广告设置引导 | 提供目标应用自己保存的广告专用传感器开关路径。优先关闭广告用途，保留正常屏幕旋转和体感功能 | 当前B站9.15路径已核实；本工具不能替所有应用拦截传感器，也不会把“看过指南”当作已设置 |
| 自动跳过开屏广告 | 你选择应用并主动授权无障碍后，在短暂开屏时段本地匹配可见按钮的文字、标识和位置，再尝试点击 | 没有可访问按钮、样式不匹配，或广告先触发跳转时，可能无法处理；不能保证零误判 |

0.1.10候选另提供部分OriginOS与Flyme的开屏专用动作限制参考，只有本机实际存在“仅开屏时禁止／拒绝”时才针对目标App使用。它不会全局关闭方向感应，也不会自动读取或修改系统开关。来源、版本边界和12个指引入口见[多品牌兼容说明](docs/MULTI_BRAND_COMPATIBILITY.md)。指导覆盖不等于广告规则或所有机型效果已通过。

B站已验证路径：**哔哩哔哩 → 我的 → 设置 → 隐私权限设置 → 关闭“允许广告访问传感器”**。该项由B站独立保存，不依赖本工具后台。不要关闭整个应用的方向权限或全局传感器。

## 第一次使用

1. 下载安装包，按手机系统提示安装；系统验证或受限制设置需本人完成。
2. 按首次引导了解本地处理与无障碍用途，选择需要处理的应用。默认不选应用、不开启自动点击，也可以稍后设置。
3. 在系统中主动开启“开屏清净 · 自动跳过”，回到App开启自动跳过，确认服务连接和应用选择均已就绪。
4. 查看防摇一摇设置引导及本机后台运行提示，再打开选中的应用观察效果。打开过设置页面不代表已经配置完成。

0.1.7将常用操作集中到首页、防摇一摇、设置三个分区，原理、权限及机型说明可展开查看；可从App重新打开五步设置引导。已有本地设置的升级用户直接进入首页，正在进行的设置流程可从保存的步骤继续。从系统设置返回时只更新真实状态，不重建整页或重置当前步骤。应用选择弹窗使用单实例，打开或构建过程中重复点击直接忽略；关闭后才可再次打开。

## 当前候选的改进范围（APK未公开）

- 只尝试控件本身的点击动作，不因首次失败或第二轮重试改点屏幕坐标。0.1.13同时停用策略、旧开关与服务的手势能力声明；这可能漏过依赖坐标的旧布局。此前B站特例只有版本名称条件，缺少维护中的数字版本及可靠遮挡校验，不能当作坐标安全证据。
- 收齐候选后再判断唯一性；多个不同按钮、扫描不完整或目标变化时停止本次开屏处理。它不能认证唯一按钮一定真实，详见[真假按钮策略](docs/FAKE_BUTTONS.md)。
- [离线规则与诊断](docs/OFFLINE_RULES.md)：文件只能收紧已内置规则，可预览、单步撤销或恢复内置；不能从文件添加选择器、代码或新应用动作。最小规则样本暂存在内存，只有本人预览并选择文件位置后才导出，不上传。
- [没有自动跳过时的设置帮助](docs/SETUP_HELP.md)：区分功能开关、应用选择、系统无障碍启用与服务实际连接，分别提供荣耀、华为4.x及华为5+说明，不要求“开全权限”。

荣耀“Android 17、B站/百度广告出现但未跳过”的反馈仍缺具体型号、MagicOS与目标应用版本及现场规则样本。当前改进不能代替该设备实测，也不把网易云没有广告算作跳过失败。

## 随时暂停或停用

- 暂时不用：关闭App内的自动跳过开关。
- 撤销能力：在系统无障碍设置中关闭本服务。
- 不再使用：直接卸载，清除本地设置。

关闭首页或划掉最近任务卡片，与暂停服务不同。无障碍服务仍需系统允许后台运行；强行停止或系统清理关闭了服务后，本工具不能自行重新授权。华为已测试设备的启动管理需允许本工具自启动、关联启动和后台活动；其他机型按实际页面检查。

## 数据和权限

App不声明`INTERNET`权限，不上传界面、应用列表或设备唯一标识，也没有广告、分析或追踪SDK。识别时会临时读取前台界面控件；系统授予的无障碍读取/点击能力比本工具实际使用范围更广。

公开0.1.7的本地偏好保存启用状态、所选应用、少量操作记录，以及引导状态和进度。本地0.1.9候选另保存导入后的规则限制、一步撤销状态和默认关闭的兼容开关；用户主动导出的文件需自行保管。分页、折叠和滚动位置仅保存在当前界面及其系统恢复状态，不写入偏好文件。设置提示会读取手机品牌/型号，应用选择会读取可启动应用清单，均在本机使用。详细保存项目、清除方式及外链边界见 [PRIVACY.md](PRIVACY.md)。

## 编译与贡献

标准工程的本轮开发基线使用JDK 21、Android SDK 35、Gradle 8.9和AGP 8.7.3，可用Android Studio打开。main仍为旧版本，查看0.1.7时先按[开发入门](docs/DEVELOPMENT.md)显式检出工作分支，再创建自己的贡献分支：

```text
# Windows
gradlew.bat :app:assembleDebug
# macOS / Linux
sh gradlew :app:assembleDebug
```

首次构建下载工具需要联网；App运行识别功能不需要联网。早期本地Gradle下载曾超时；目前源码提交931f2b9已通过远程标准assembleDebug与lintDebug（见[验证记录](docs/GRADLE_VALIDATION.md)）。本地预览包另通过Google SDK 35 / Build Tools 35.0.0和JDK 21的本机构建路径验证：

```powershell
.\tools\build-local.ps1 -SdkRoot C:\Android\Sdk -JdkRoot C:\Java\jdk-21 -OutDir C:\build\SplashGuard
```

该脚本生成可调试的开发预览包。密钥只保存在本地输出目录，不得上传；稳定发布需另行使用正式签名、非调试构建并重新验收。
