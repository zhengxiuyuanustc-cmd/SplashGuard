# 开屏清净 · SplashGuard

**防摇一摇广告设置引导 + 自动跳过开屏广告。** 优先用好应用自己的广告专用开关，再通过无障碍服务尝试点击明确的“跳过广告”按钮。无需 root，识别在本机完成。

**[下载与机型设置网站](https://zhengxiuyuanustc-cmd.github.io/xiuyuanzheng.github.io/splashguard/)** · [GitHub 发行页](https://github.com/zhengxiuyuanustc-cmd/SplashGuard/releases) · [隐私说明](PRIVACY.md)

网站和下载免注册、免登录。本文对应工作分支 `feature/simple-ui-onboarding` 的 **0.1.7 / versionCode 8 候选**：已完成本地 SDK 构建及99项纯Java检查，用户已反馈打开App及重复选择窗口的修正功能正常。设备随后断开，最新候选未完成ADB版本与APK哈希回读；不能将用户反馈当作该二进制已核验安装。GitHub CI及网页/发行上传仍待实际发布记录确认，文档更新不代表已经公开；当前main与既有公开发行仍为0.1.4。下载前以网站实际按钮标注为准。

当前公开包采用开发签名并开启调试，属于预览构建，尚非正式稳定版。Android 8.0（API 26）及以上可试用；实机覆盖目前限于华为 GOA-AL80 / HarmonyOS 4.2 / Android API 31，其他机型和广告样式仍需验证。

## 两项功能，各自怎么起作用

| 功能 | 如何帮助你 | 边界 |
| --- | --- | --- |
| 防摇一摇广告设置引导 | 提供目标应用自己保存的广告专用传感器开关路径。优先关闭广告用途，保留正常屏幕旋转和体感功能 | 当前B站9.15路径已核实；本工具不能替所有应用拦截传感器，也不会把“看过指南”当作已设置 |
| 自动跳过开屏广告 | 你选择应用并主动授权无障碍后，在短暂开屏时段本地匹配可见按钮的文字、标识和位置，再尝试点击 | 没有可访问按钮、样式不匹配，或广告先触发跳转时，可能无法处理；不能保证零误判 |

B站已验证路径：**哔哩哔哩 → 我的 → 设置 → 隐私权限设置 → 关闭“允许广告访问传感器”**。该项由B站独立保存，不依赖本工具后台。不要关闭整个应用的方向权限或全局传感器。

## 第一次使用

1. 下载安装包，按手机系统提示安装；系统验证或受限制设置需本人完成。
2. 按首次引导了解本地处理与无障碍用途，选择需要处理的应用。默认不选应用、不开启自动点击，也可以稍后设置。
3. 在系统中主动开启“开屏清净 · 自动跳过”，回到App开启自动跳过，确认服务连接和应用选择均已就绪。
4. 查看防摇一摇设置引导及本机后台运行提示，再打开选中的应用观察效果。打开过设置页面不代表已经配置完成。

0.1.7将常用操作集中到首页、防摇一摇、设置三个分区，原理、权限及机型说明可展开查看；可从App重新打开五步设置引导。已有本地设置的升级用户直接进入首页，正在进行的设置流程可从保存的步骤继续。从系统设置返回时只更新真实状态，不重建整页或重置当前步骤。应用选择弹窗使用单实例，打开或构建过程中重复点击直接忽略；关闭后才可再次打开。

## 随时暂停或停用

- 暂时不用：关闭App内的自动跳过开关。
- 撤销能力：在系统无障碍设置中关闭本服务。
- 不再使用：直接卸载，清除本地设置。

关闭首页或划掉最近任务卡片，与暂停服务不同。无障碍服务仍需系统允许后台运行；强行停止或系统清理关闭了服务后，本工具不能自行重新授权。华为已测试设备的启动管理需允许本工具自启动、关联启动和后台活动；其他机型按实际页面检查。

## 数据和权限

App不声明`INTERNET`权限，不上传界面、应用列表或设备唯一标识，也没有广告、分析或追踪SDK。识别时会临时读取前台界面控件；系统授予的无障碍读取/点击能力比本工具实际使用范围更广。

本地偏好保存启用状态、所选应用、少量操作记录，以及0.1.7的引导状态和进度。分页、折叠和滚动位置仅保存在当前界面及其系统恢复状态，不写入偏好文件。设置提示会读取手机品牌/型号，应用选择会读取可启动应用清单，均在本机使用。详细保存项目、清除方式及外链边界见 [PRIVACY.md](PRIVACY.md)。

## 编译与贡献

标准工程的本轮开发基线使用JDK 21、Android SDK 35、Gradle 8.9和AGP 8.7.3，可用Android Studio打开。main仍为旧版本，查看0.1.7时先按[开发入门](docs/DEVELOPMENT.md)显式检出工作分支，再创建自己的贡献分支：

```text
# Windows
gradlew.bat :app:assembleDebug
# macOS / Linux
sh gradlew :app:assembleDebug
```

首次构建下载工具需要联网；App运行识别功能不需要联网。标准Gradle路径曾因官方发行包下载超时未进入编译，尚无通过记录。已有预览包通过Google SDK 35 / Build Tools 35.0.0和JDK 21的本机构建路径验证：

```powershell
.\tools\build-local.ps1 -SdkRoot C:\Android\Sdk -JdkRoot C:\Java\jdk-21 -OutDir C:\build\SplashGuard
```

该脚本生成可调试的开发预览包。密钥只保存在本地输出目录，不得上传；稳定发布需另行使用正式签名、非调试构建并重新验收。
